# Crypto Market Analysis 2026
**Tools:** Python, pandas, matplotlib  
**Data:** CoinGecko API

## Projects

### 1. Bitcoin Price Analysis (365 days)
Analysis of Bitcoin price dynamics over the past year.
- Min / Max / Average price
- Monthly average breakdown
- Price trend visualization

### 2. Was Crypto Trading Profitable in Early 2026?
Analysis of top 50 cryptocurrencies from January to April 2026.
- Profitability analysis for 5 major coins
- Discovery of 19 profitable coins out of 45
- Top 5 best performing coins: Memecore (+96%), Hyperliquid (+72%), Zcash (+50%)

## Files
- `Crypto_2026_Analysis.ipynb` — main notebook with full analysis
- `crypto_top50.csv` — top 50 coins dataset
- `btc_history.csv` — Bitcoin 365-day history
